# Livewire Development
Use the established class-based Livewire convention. Validate and authorize in server-side actions, keep state server-side, use `wire:key` in loops, provide loading/disabled states, and do not introduce a separate SPA without an architecture decision. Read `.ai/rules/livewire.md` first.
