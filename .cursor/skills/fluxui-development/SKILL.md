# Flux UI Development
Use Flux controls and existing `x-ui.*` presentation components. Confirm exact Heroicon names; do not guess. For Lucide icons run `php artisan flux:icon <name>` and commit the generated `resources/views/flux/icon/*.blade.php` file. Follow `docs/UI-DESIGN-SYSTEM.md` and verify rendered responsive/dark-mode behavior.
