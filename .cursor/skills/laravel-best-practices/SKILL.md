# Laravel Best Practices
Read `.ai/rules/index.md` and matching rule files first. Prefer Laravel-native conventions, Eloquent directly, Policies, focused Actions/Services for substantial workflows, migrations, transactions for critical multi-record writes, factories/Pest tests, and `composer ci:check` before completion. Preserve MySQL/cPanel compatibility and avoid speculative infrastructure or abstractions.
